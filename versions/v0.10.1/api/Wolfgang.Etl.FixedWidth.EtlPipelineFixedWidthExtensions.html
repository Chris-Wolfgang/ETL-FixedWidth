Class-named fixed-width source factories and sink terminators for the fluent Wolfgang.Etl.Abstractions.EtlPipeline chain (issue #253). Source factories hang off Wolfgang.Etl.Abstractions.EtlPipeline so a pipeline reads EtlPipeline.Create().FixedWidthExtractor<Person>("people.txt"); sink terminators hang off Wolfgang.Etl.Abstractions.IEtlPipeline<T> so it ends … .FixedWidthLoader<Person>("out.txt").RunAsync().

Remarks

Path-based factories own the file stream they open and dispose it after the run (success or failure). Factories that accept a caller-supplied Stream, TextReader, TextWriter, or a pre-built extractor do not dispose it — the caller owns the lifecycle and, for a writer, is responsible for flushing it. The fluent setters returned by these factories map 1:1 to the underlying FixedWidthExtractor<T> / FixedWidthLoader<T> properties; encoding is set via the builder's Encoding method.
