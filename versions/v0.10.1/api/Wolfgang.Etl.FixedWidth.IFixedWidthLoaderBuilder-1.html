A fluent builder for a fixed-width loader that terminates a generic Wolfgang.Etl.Abstractions.EtlPipeline. Returned by the FixedWidthLoader sink terminators in EtlPipelineFixedWidthExtensions.

public interface IFixedWidthLoaderBuilder<T> : IEtlPipelineSink where T : notnull

Type Parameters

T

The record type consumed by the loader.

Inherited Members
IEtlPipelineSink.RunAsync(IProgress<EtlPipelineProgress>, CancellationToken)

Remarks

Each configuration method maps one-to-one to a settable property on FixedWidthLoader<TRecord> and returns the same builder so calls chain. Because the builder is an Wolfgang.Etl.Abstractions.IEtlPipelineSink, the loader is materialized and the pipeline runs when RunAsync(IProgress<EtlPipelineProgress>, CancellationToken) is called.
