Configuration for a FixedWidthLoader<TRecord> constructed over a Stream: everything in FixedWidthLoaderOptions plus the Encoding used to encode the bytes. The TextWriter constructors take the base record instead, because a writer already owns its encoding and an Encoding there would be settable but inert.
