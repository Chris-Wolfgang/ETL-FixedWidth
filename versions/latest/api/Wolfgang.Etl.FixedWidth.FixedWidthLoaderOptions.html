Configuration for a FixedWidthLoader<TRecord>, supplied to its constructor. Carries every formatting setting that is independent of the output shape; the Stream constructors take the derived FixedWidthLoaderStreamOptions, which adds the byte-encoding Encoding a TextWriter caller has already decided.

Remarks

Every property is init-only: settle the configuration before a run rather than mutating it during one (ADR-0009). The documented defaults live on the property initializers, so no constructor can diverge from them; a null options argument means "all defaults".
