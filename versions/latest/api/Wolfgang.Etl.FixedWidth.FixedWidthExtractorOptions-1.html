Configuration for a FixedWidthExtractor<TRecord>, supplied to its constructor. Carries every parsing setting that is independent of the input shape; the Stream constructors take the derived FixedWidthExtractorStreamOptions<TRecord>, which adds the byte-decoding Encoding a TextReader caller has already decided.

Remarks

Every property is init-only: settle the configuration before a run rather than mutating it during one (ADR-0009). The documented defaults live on the property initializers, so no constructor can diverge from them; a null options argument means "all defaults". Members that reject a value do so from the init accessor, so an invalid record cannot be constructed.
