Remarks

Each configuration method maps one-to-one to a settable property on FixedWidthExtractor<TRecord> and returns the same builder so calls chain. Configuration is recorded and applied when the first pipeline operation — a Through stage, a sink terminator such as FixedWidthLoader, or AsAsyncEnumerable(CancellationToken) — materializes the extractor; calling a setter after that throws InvalidOperationException.
