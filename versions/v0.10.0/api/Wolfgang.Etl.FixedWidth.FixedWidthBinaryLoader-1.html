Class FixedWidthBinaryLoader<TRecord>

Namespace

Writes records of type TRecord to a fixed-length binary record stream (mainframe / COBOL, #21) — the write counterpart of FixedWidthBinaryExtractor<TRecord>. Each record is encoded to a fixed number of bytes (the field byte widths) and written back-to-back with no delimiters, encoding COMP-3 packed-decimal and COMP binary-integer fields alongside text.

public sealed class FixedWidthBinaryLoader<TRecord> : LoaderBase<TRecord, FixedWidthReport>, ILoadWithProgressAndCancellationAsync<TRecord, FixedWidthReport>, ILoadWithProgressAsync<TRecord, FixedWidthReport>, ILoadWithCancellationAsync<TRecord>, ILoadAsync<TRecord>, IReportsItemErrors, IAsyncDisposable, IDisposable where TRecord : notnull
