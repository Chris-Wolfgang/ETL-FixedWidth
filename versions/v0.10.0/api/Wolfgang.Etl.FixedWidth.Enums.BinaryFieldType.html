How the bytes of a FixedWidthBinaryFieldAttribute field are decoded (#21).

public enum BinaryFieldType

Fields

Binary = 2

COBOL COMP / COMP-4 binary integer: a big-endian value, two's-complement signed by default (see Signed).

PackedDecimal = 1

COBOL COMP-3 packed decimal (BCD): two digits per byte with a sign nibble in the low nibble of the last byte. Use Scale for the implied decimal places.

Text = 0

Character data — the bytes are decoded to text with the extractor's encoding (ASCII, a code page such as EBCDIC, UTF-8, …) and then converted to the property type, exactly like a text fixed-width field.
