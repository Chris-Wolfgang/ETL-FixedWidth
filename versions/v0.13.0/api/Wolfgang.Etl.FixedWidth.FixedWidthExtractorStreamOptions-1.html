Configuration for a FixedWidthExtractor<TRecord> constructed over a Stream: everything in FixedWidthExtractorOptions<TRecord> plus the Encoding used to decode the bytes. The TextReader constructors take the base record instead, because a reader has already decoded its bytes and an Encoding there would be settable but inert.
