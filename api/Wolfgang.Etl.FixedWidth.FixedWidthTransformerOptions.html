Configuration for a FixedWidthTransformer<TSource, TDestination>, supplied to its constructor. The transformer has no settings of its own beyond the base-stage ones it inherits (ReportingInterval, MaximumItemCount, SkipItemCount, ErrorPolicy); the record exists so the transformer is configured the same way as every other stage (ADR-0009).

[SuppressMessage("Major Code Smell", "S2094:Classes should not be empty", Justification = "ADR-0009: every stage takes its own options record so provider-specific settings can be added without a breaking constructor change; the transformer simply has none yet.")]
